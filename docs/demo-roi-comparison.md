## Enterprise Data Privacy: The API Question

### "But the AI API calls still send data out, right?"

**Yes — but enterprises have options.** This is a valid concern, and WorkerMill supports multiple deployment tiers based on security requirements.

### Tier 1: Standard Deployment (Most Users)

```
Your AWS Account                    AI Provider
┌──────────────┐                   ┌──────────────┐
│ WorkerMill   │ ──── HTTPS ────→  │ Anthropic    │
│ (your VPC)   │                   │ API          │
└──────────────┘                   └──────────────┘
```

**Data handling:**
- API calls go over HTTPS (encrypted in transit)
- **Anthropic API**: Data retained 7 days (down from 30 days as of Sept 2025), never used for training
- **OpenAI API**: Data retained 30 days for abuse monitoring, never used for training

**Best for:** Most enterprises, startups, non-regulated industries

> "Under ZDR arrangements, Anthropic does not store inputs or outputs except where needed to comply with law or combat misuse."
