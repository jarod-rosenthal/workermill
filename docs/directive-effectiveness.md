# Directive Effectiveness

> **Beta** — This feature is in active development.

Track and optimize the performance of worker directives. Monitor success rates, identify underperforming directives, and run experiments to improve outcomes.

## Overview

Directives are instructions that guide how AI workers approach different types of tasks. Each persona has directives that define their behavior, coding standards, and decision-making patterns. The Directive Effectiveness dashboard helps you:

- Monitor directive performance across all personas
- Identify directives with low success rates
- Detect gaps where directives are missing or ineffective
- Run A/B experiments to compare directive versions
- Get recommendations for directive improvements

## Key Metrics

| Metric | Description |
|--------|-------------|
| **Total Directives** | Count of active directives per organization |
| **Avg Success Rate** | Across all tasks where each directive was applied |
| **Running Experiments** | Active A/B tests comparing directive versions |
| **Health Alerts** | Actionable alerts for underperforming directives |

## Directive Health

Each directive is scored on:

- **Success Rate** — Tasks completed successfully when this directive was active
- **Application Rate** — How often the directive is actually followed by workers
- **Conflict Rate** — How often this directive conflicts with other directives
- **Coverage** — Percentage of task types this directive applies to

**Health levels:**
- 🟢 **Healthy** (≥75% success rate) — Directive is effective
- 🟡 **Watch** (50–74%) — Monitor for degradation
- 🔴 **Alert** (<50%) — Needs attention or replacement

## Running Experiments

Compare directive versions with controlled A/B experiments:

1. Go to **Settings → Directive Effectiveness**
2. Select a directive to experiment with
3. Create a variant (Directive B)
4. Set traffic split (e.g., 50/50)
5. Run for a minimum of 20 tasks
6. Review results and promote the winner

Experiments automatically pause if the variant causes significantly more failures.

## Directive Gaps

The system identifies **directive gaps** — task types where no directive provides guidance:

- Workers in these situations rely on model defaults
- Gaps often correlate with higher escalation rates
- The system suggests directive topics based on common failure patterns

## Getting Recommendations

The Directive Effectiveness system can suggest improvements:

1. Select a low-performing directive
2. Click **Get Recommendation**
3. Review the suggested rewrite
4. Test in an experiment before promoting

Recommendations are generated by analyzing:
- Task execution logs where the directive was applied
- Common failure patterns
- Successful patterns from similar directives across organizations
