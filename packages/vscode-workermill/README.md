# WorkerMill for VS Code

Watch AI experts build your project — real-time monitoring and control for your WorkerMill AI engineering team.

## Features

- **Run Jira & GitHub issues** as AI worker tasks directly from VS Code
- **Real-time task logs** streamed to pseudoterminal tabs
- **Live code changes** — see what AI workers are modifying as they work
- **Activity feed** — follow expert collaboration in real-time
- **Product Build** — decompose a spec into a full board of tasks
- **One-click onboarding** — sign up with GitHub, no terminal commands needed

## Getting Started

1. Install the extension from the VS Code Marketplace
2. Open the WorkerMill sidebar and click **Get Started with GitHub**
3. The extension downloads the agent binary, connects, and you're ready to go

Or if you already have an account: **Sign In** or **Use API Key**.

## Requirements

- A [WorkerMill](https://workermill.com) account (free tier available)
- Git installed on your system
- Claude Code CLI (prompted during setup)

## Commands

| Command | Description |
|---------|-------------|
| **WorkerMill: Run Task** | Run a Jira/GitHub issue by key |
| **WorkerMill: Search Issues** | Search and run issues from a picker |
| **WorkerMill: Product Build** | Decompose a .md spec into board cards |
| **WorkerMill: Run as Task** | Run a .md file as a single worker task |
| **WorkerMill: Talk to Worker** | Send a message to an active worker |
| **WorkerMill: Show Task Logs** | Open log terminal for an active task |
| **WorkerMill: Approve Plan** | Approve or reject a pending plan |
| **WorkerMill: Settings** | Open WorkerMill settings panel |
