# Connect a Repository

WorkerMill needs access to your repository so workers can read code, create branches, and open pull requests.

**Option 1 — GitHub App (recommended)**
Install the WorkerMill GitHub App for one-click access. Grants only the permissions needed.

**Option 2 — Personal Access Token**
Paste a GitHub PAT with `repo` scope. Works with any Git hosting provider (GitHub, GitLab, Bitbucket).

Open **Settings** in the WorkerMill sidebar to configure your SCM connection.
