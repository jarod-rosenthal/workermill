# Run Your First Task

You're ready to send work to AI agents.

**Quick task from a file:**
1. Right-click any `.md` file in the Explorer
2. Select **WorkerMill: Run as Task**
3. Watch the worker execute in the Coordination Feed

**Full spec build:**
1. Write a PRD or feature spec as a `.md` file
2. Right-click and select **WorkerMill: Product Build**
3. WorkerMill decomposes it into stories and assigns them to specialized AI workers

Workers will create branches, write code, run quality gates, and open pull requests automatically.
