# Welcome to WorkerMill

WorkerMill orchestrates autonomous AI coding agents that plan, execute, and deliver pull requests — all from your editor.

### How it works

| Step | What happens |
|------|-------------|
| **You describe the work** | A task description, issue key, or full product spec |
| **A planner decomposes it** | Stories with target files, personas, and dependencies |
| **Experts execute in parallel** | Each story assigned to a persona-matched AI worker |
| **Quality gates enforce standards** | Lint, typecheck, tests, CI — failures trigger auto-fix |
| **A PR is delivered** | Consolidated branch with all changes, ready for review |

### Two ways to run

- **Cloud** — sign in, connect your repo, and go. Workers run on managed infrastructure.
- **Self-hosted** — run the full platform on your own machine with your own API keys.

Choose **Sign In** below to get started with cloud, or **Local Development** if you're self-hosting.
